# Midnight Fridge Roast

A one-line roast of a smart fridge that refuses to open after midnight.

## The entry

> After midnight my fridge locks itself like a nightclub bouncer, and I have to remind it I own the club, the drinks, and the leftovers.

## Run

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (one line, under 200 characters).
